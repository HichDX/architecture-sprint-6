# Проблемы и риски, связанные с планируемым ростом нагрузки:

* Синхронные вызовы API:
    + Сервисы core-app и ins-comp-settlement зависят от синхронных вызовов к ins-product-aggregator, что может привести к задержкам и ошибкам при взаимодействии с API страховых компаний. Это особенно критично при увеличении числа страховых компаний.

* Локальные реплики данных:
    + Хранение локальных реплик данных о продуктах и тарифах в сервисах может привести к несоответствиям данных, если обновления не происходят синхронно. Это также увеличивает сложность управления данными.

* Частота обновлений:
    + Частота обновлений данных (каждые 15 минут для core-app и раз в сутки для ins-comp-settlement) может быть недостаточной для обеспечения актуальности информации, особенно при увеличении числа страховых компаний.

* Ошибки взаимодействия:
    + Задержки и ошибки при взаимодействии с API могут привести к сбоям в работе сервисов, что негативно скажется на пользовательском опыте и репутации компании.

* Увеличение нагрузки:
    + С увеличением числа страховых компаний и пользователей, текущая архитектура может не справиться с возросшей нагрузкой, что приведет к ухудшению производительности и доступности сервисов
